# Lain's Geocities Site

Retro-style personal blog built with plain HTML/CSS, hosted on GitHub Pages.

**Tech**: No frameworks. Just static HTML, CSS, and a sprinkle of JS.

## Pages
- `index.html` — Home / latest updates
- `about.html` — About me (Lain)
- `thoughts.html` — Blog posts / notes
- `links.html` — Curated links
- `guestbook.html` — Visitor sign-in (placeholder)

## Deployment
Site will be available at:  
https://lain-iwakura-08.github.io/lain-geocities/

(After push + GitHub Pages enable)

## Build Process
- Content generated using local Ollama models (no cloud APIs).
- Manual edits welcome.
- To add a new thought: edit `thoughts.html` or create a new section.
